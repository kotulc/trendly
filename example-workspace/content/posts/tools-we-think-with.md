The best tools make it easier to return to a thought. I keep coming back to the idea that a draft should be a file I can open anywhere, including years after the app that made it has disappeared.

> The network is optional.
>
> — [Ink & Switch, *Local-first software*](https://www.inkandswitch.com/essay/local-first/)

## What stayed with me

Owning the file changes what I can do with it. I can annotate a source, let an agent suggest a rewrite, or move the draft to another editor without asking a service to export it. That makes me more willing to invest time in the work.

The question I want to follow is how much coordination we can add while keeping the files easy to understand.
